#Я действовал по такой логике: нахожу файл -> прочитываю строки -> показываю пользователю -> дальше использую цикл для ввода двух координат -> затем меняю решетки на звездочки и сохраняю изменения -> показываю результат.

программа ищет файл txt.txt на рабочем столе, если файла нет, то останавливает работу весь файл загружаем в память в виде набора строк, каждой строке присвоен номер по порядку, а каждому символу номер слева направо На экран выводятся все строки с их номерами, чтобы было понятно какие координаты ввести Пользователь вводит числа. Программа разбирает ввод и проверяет. Если формат неверный — просит повторить Если в указанном месте решётка — то она заменяется на звёздочку. Если там точка или уже звёздочка, то ничего не происходит Обновлённое содержимое записывается. В конце выводится итоговый файл и сколько символов заменено, сколько пропущено
